1. Project Overview
The project was a digital website portfolio of ourselves, our projects and how to contact us
2. Website Pages
The website uses the 4 basic pages
3. Responsive Design
I used three separate CSS files appropriately named laptopviewport, tabletviewport and mobileviewport which are all called on the beginning of all four HTML files. They work the same by reading the width and height of the browser and changing the currently active viewport
4. Gradients
Gradients were made on the header and footer of every page, rotated -45 degrees and 135 degrees to slant them
5. Colour Scheme
The colour scheme is based on a monochromatic scheme using #240033, #3D0054, #6A1B87, #9C4ABA, #D48EED, #F1CCFF based on a deep blue based purple as it is my favorite color and the complementary colours are too harsh to look presentable on the website
6. Testing and Validation
	HTML VERIFICATION
All HTML files passed validation with the only exception being the 'contactme' as it did not have a header. the header was removed to reduce redundancy in the page due to the browser tab and the h1 header both saying 'CONTACT ME'
	CSS VERIFICATION
All 3 CSS files passed the verification and gained the rating of CSS level 3 with SVG
	LINK CHECKING
No external links were added to this document, all HREF are within the documents itself
	SPELLING
