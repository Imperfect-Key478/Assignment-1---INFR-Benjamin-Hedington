Web Jeopardy Game - First Year University

This was my final for my first year coding class at Ontario Tech University. It was made in Python with four others, meant to be styled like a old text based DOS game It was rudamentary with no timer, simple scoring and inability to save high scores, but it worked and was a interesting idea to solidify my understanding.

Boss Fight Game - Grade 12

My grade 12 final project was massively ambitious for being a solo project and made in a week. Grade 12 was focused on game development the same as grade 11 which was again all in C#. I had an idea of an adventure based game where you had to find weapons to beat a boss, but it ended up being made in 36 hours as a single boss fight.

Three Player Co-op Game - Grade 11

Grade 11 final project was made with C# with two other friends, Chase and Matthew, both of which go to Ontario Tech University and Chase is going into game development. It was based off of a series of rage games called "Boshy games" based on an original flash game called "I Wanna Be The Guy" which was a platformer meant to be brutally difficult to beat casually. We used that as our base to build a three player co-op game around a singular boss fight that scaled with the number of players.

Personal Website - Grade 4
